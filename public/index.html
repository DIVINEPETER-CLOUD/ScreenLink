ScreenLink

Share your screen with a friend in real time. The person sharing always chooses what to share.

1. Create a private room

Create a room link and send it only to the person you want to connect with.

Anyone who gets the room link may try to join. Keep it private.

2. Join the room

The person sharing clicks “Share my screen” and approves the browser prompt. The other person clicks “View friend's screen”.

Not connected.

Privacy: Screen sharing requires the sharer's explicit browser permission. This app cannot secretly turn on screen sharing. Stop at any time using the button here or the browser's sharing controls.

ScreenLink is an early demo. Use HTTPS when deployed. Some networks may need a TURN relay server for WebRTC to connect reliably.
